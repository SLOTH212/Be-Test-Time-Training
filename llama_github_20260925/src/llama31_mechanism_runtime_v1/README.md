# Llama-3.1-8B mechanism runtime V1

Engineering validation only. The supplied debug trajectories and synthetic tokenizer IDs are not benchmark results. No formal Stage2 model, Fixed8, Dynamic, or paper mechanism run is started by this package.

The `reference` directory contains byte-identical selected source files from Qwen mechanism package `ce9ee7c7066d0413e4fcf90b69543cfa605ac1761af8d849ddb2d61ccd6fb1a8`. Imports verify every copied file against `provenance/immutable_reference.json`. Generic action mapping, exact reverse, R2 enumeration/tie selection and K/P plans are reused. Named original K/P definitions are compiled with Llama cache/NTP classes and chunk literal 4096. Historical imports, paths, mains and scoring programs are not executed. No Transplant, Criticality or Observability runtime is introduced.

Six TTT layers are `[0,6,12,18,24,30]`; canonical actions are `[OFF,L0,L6,L12,L18,L24,L30,ALL]`. The preserved NTP core computes apply-then-update with LR 1, Frobenius clipping 1e-5, complete chunks only. OFF retains current functional fast weights and computes ordinary linear output while omitting updates. Whole-trajectory unused layers follow the inherited non-TTT path. Generation never updates fast weights.

Reset is layer-major, local state replacement with checkpoint down-projection weights immediately before the first chunk of the terminal equal-action run. Existing forward/KV context continues; no prompt restart, earlier chunk replay, cache rollback or RNG reset occurs. Unused layers are implicitly at checkpoint state. Eligibility is the separately copied resolution-aware V2 CANDIDATE, engineering only: switched-to human chunk <= max(2,N//4), late-half modal occupancy >= .80, canonical action tie order.

K/P exactly preserves the recovered source contract: native effective boundary weights in every cell; K chooses control or native donor prefix keys AND values in every attention layer; P0 explicitly materializes all six states, P1 materializes the native full-sequence used-layer union. F11 closure concerns the continuation after injection and generated prediction, not the intentionally different control prefix before injection. Prefix KV injection and layer-major recomputation are unchanged source operations.

Two scope resolutions are explicit. The canonical R2 family requires A != B and 1 <= tau < N, excluding constant degeneracies. For N=4 and eight actions it contains exactly 168 unique schedules; the independent test exhausts all 8^4 sequences and selects those with exactly one transition. No heuristic replaces enumeration. The requested GPU validation executes three selected candidates, not the full family. Historical Selective Deletion removed an accumulated layer component at a boundary. This request explicitly asks to omit exactly one selected chunk/layer update instead: the adapter suppresses that core update, retains its apply output/current state, and recomputes every later operation. It is labeled single-update deletion, not byte-identical historical component deletion.

Run `python -B test_contracts.py` from this extracted directory for CPU tests. `python -B cli.py smoke` is a dry run and reports the source directory actually imported. The bundled shell scripts resolve this package relative to their own location, or `LLAMA_MECHANISM_ROOT` when deployed externally. `--execute` is required for bounded GPU work. Only physical GPUs 0–3 are visible; one independent model per device; cooperative locks prevent duplicate mechanism workers. The validated external Llama port and debug DCP are intentionally not packaged.

Future formal launch is prepared only. Provide `--stage2-authority`, `--trajectory-authority`, `--output-root`, and `--execute`. Stage authority schema is `LLAMA_STAGE2_FINAL_AUTHORITY_V1`, status FINAL, DEBUG_ONLY false, matching Llama revision, model_path and relative file SHA256 map, plus inference_dcp contained within and fully bound by that map. Dynamic authority schema is `LLAMA_DYNAMIC_TRAJECTORY_AUTHORITY_V1`, DEBUG_ONLY false, FORMAL_RESULTS true, parent_stage2_sha256, the five-stage chain, trajectory_path/SHA256, mechanisms `[reverse,reset,kp,deletion,r2]`, and scorer_path/SHA256. The scorer module provides `score(row, replay_record)`; this keeps future benchmark-specific scoring outside the mechanism core.

Every JSONL trajectory has sample_id, task, prompt_token_count, chunk_size, complete_decision_chunks, action_sequence, canonical actions/layers, model_revision, inference_authority_sha256, prompt_ids_sha256, and optional native_score. Formal execution additionally requires parent_stage2_sha256, completed true, DEBUG_ONLY false, prompt_ids_path (JSON token IDs), max_new_tokens, native_score/native_prediction_sha256, and declared deletion_targets with zero-based chunk_index_0 and layer. Strict parent replay gates run before interventions. This is a documented interface for future exporters, not an assertion that an unknown future output schema already matches it.

Completed sample JSON receipts are authoritative only with matching authority and result hash. Temporary files are ignored; restarts rebuild the sample from its checkpoint. Deterministic SHA256(sample_id) modulo 4 ownership and output namespaces prevent candidate/worker collisions. CPU tests simulate partial output and restart without killing GPU jobs.

Numeric evidence stores full SHA256 fingerprints, compact per-layer/per-chunk state transitions, chunk-end logits, greedy prediction hashes, real update counts and GPU telemetry. Dense weights, caches, DCPs, and datasets are excluded from the archive. Base checkpoint files are hashed before/after; in-memory original parameters are hashed for each worker. Functional fast states are intentionally separate.
